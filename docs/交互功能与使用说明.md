## 现在可以操作的功能

| 页面 | 操作与反馈 |
| --- | --- |
| 首页 Index | 点击格式浏览器、转换执行器、任务记录进入对应页面；能力检测单独查询 Native 状态，检测期间显示“检测中”，5 秒超时后可再次点击；会话任务数实时更新 |
| 格式浏览器 FormatBrowser | 按名称/ID/扩展名搜索，按全部/PDF/图片/Office/文本/音频筛选；点击格式卡片展开/收起 ID、扩展名、MIME 和规划操作；点击“使用此格式演示”带源格式跳转 |
| 转换执行器 ConverterPage | 选择源/目标格式，在可折叠面板选择快速/均衡/高保真、转换意图与最低期望等级；显示路线等级、直转/中转及意图；填写示例文件名，确认配置摘要后执行五阶段演示；可暂停/继续/取消；完成后可展开模拟报告 |
| 任务记录 TaskHistory | 查看会话任务、状态、耗时和保真选项；活动任务可控制，完成任务可展开模拟报告；清除已结束记录保留排队、运行和暂停的任务；空列表提供开始入口 |
| 功能指南 FeatureGuide | 保留项目已有的功能分类与格式路线说明，仍使用共享注册数据 |

建议首次体验：进入“转换执行器” → 选择 PDF→PNG → 展开“保真度设置”，保留均衡/保留布局/标准保真 → 填入“报告.pdf” → 点击开始并确认摘要 → 约 3.5 秒完成 → 展开保真度报告。快速/高保真分别演示约 2/6 秒；可暂停、取消或跳转任务记录，返回后继续查看状态。详细参数与验收用例见[保真度控制与参数管道](保真度控制与参数管道.md)。

所有演示均不读写用户文件，不上传、不创建实际输出、不调用 Native.execute。文件名输入只是模拟选择。演示不进行真正的格式解析、加密/签名检测或保真校验，真实路线可用数仍为 0。

## 在 DevEco 中查看

使用 DevEco 打开工程根目录，在 `entry/src/main/ets/pages/Index.ets` 中打开预览。五个页面已注册到 main_pages.json；保真度功能没有修改该路由文件。若界面仍显示旧内容，可关闭并重新打开预览器或执行重新加载。

查看布局与验证点击属于不同操作：请启用当前 DevEco 预览器支持的交互预览模式进行操作，具体入口名称以安装版本为准。若预览器中的页面路由 API 不可用，跳转会显示提示，可单独打开 FormatBrowser、ConverterPage、TaskHistory 的预览。完整页面导航最终以签名后在模拟器/真机运行的结果为准。

官方预览概述说明了保存源码后查看界面变化的流程：[华为 DevEco 预览器概述](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/ide-previewer-overview-V5)。本次没有控制 DevEco 窗口，也没有宣称预览器点击测试已经执行。

## 实现方法与提示词适配

用户提供的文本文档已按原字节保存于 `docs/reference/交互实现提示词-用户原文.txt`。其中嵌入的工具调用及“文件已保存”是历史文本，不作为本机操作结果。本次以真实源码和构建日志作为交付依据。

- 沿用当前用户侧动态导入的 NativeBridge，并补齐失败后重试、Native 导出检查、受控路径/哈希/预算检查和成功结果校验；不删除原 13 个接口或原 DTO。
- Native 是否成功加载与转换引擎是否可用分别判断。不能仅凭 isNativeAvailable=true 就对占位引擎执行“真实转换”；当前所有规划路线保持 planned。
- 使用现有 registry 的实际分类 pdf/image/office/text/audio。提示词中的 document/spreadsheet 不属于当前配置分类，Office 包含文档、演示和表格格式，名称/扩展名搜索可进一步定位。
- 使用强类型的 DemoTask、显式状态方法和复制快照，避免 Partial/Object.assign 引入弱类型更新；@State 数组通过订阅刷新，组件以输入属性/事件回调通信。
- 按配置过滤单输入路线及所选意图/最低等级，默认直转优先、同类按 priority 升序；快速模式优先步骤少的路线，高保真模式在同一意图内优先更高规划等级。合并等多输入操作不混入单文件演示，达不到最低等级时不能启动。
- 用按钮状态和提示文字表示忙碌，不假设通用 Button 存在 loading 属性。页面展示 Toast、错误说明、空状态、结果及状态徽标。
- 演示任务只保存在本次应用会话内，最大 100 条，单个计时器/单并发 FIFO。暂停时不累计暂停时间，取消后不能重新完成。页面离开只注销订阅，任务继续；UIAbility 销毁时取消活动演示并清理计时器。
- 受保护扩展名被输入校验阻断；此处只是名字检查，不能替代正式 Native 内容保护检测器。

## 修改文件位置

页面位于 `entry/src/main/ets/pages`。交互组件包括 ActionCard、StatusBadge、FormatTag、PageHeader；保真度组件为 QualitySelector、FidelityReportCard。

状态结构位于 `models/InteractionModels.ets`；规划筛选和会话任务管理位于 `viewmodel/ConversionPlanner.ets`、`TaskStore.ets`；导航与反馈位于 `common/UiFeedback.ets`。FoundationViewModel 保留能力检查职责并加入超时。

当前资源配置是五页路由，本轮未修改。原完整 NativeProtocol.ets、Protocol.d.ts、converter.h、18 格式/43 路线 JSON 和原样归档均保留；没有为演示升级真实转换能力。交互改动与保真度改动的快照位置分别见 IMPLEMENTATION_STATUS.md。
