# 文件授权与输入管理（P0）

更新日期：2026-09-29。本次完成 ArkTS 输入管理和真实提交入口，采用用户已批准的兼容方案；原有 18 种格式、43 条规划路线、演示调度与保真筛选保持不变。当前 C++ 会话、工作区和转换引擎仍为占位，真实可执行路线仍为 0。

## 用户入口

ConverterPage 在有 Stage 上下文及文件服务能力时显示“选择源文件”。可选择最多 10 个文件，显示原名、大小、推断格式和移除按钮；复制过程中显示状态并禁止重复导入/提交。未选真实文件时，原演示名称、确认、队列、暂停/恢复和报告流程继续可用。

导入成功后，源格式按第一份文件的注册格式选中，后续仍使用原单文件路线、意图、最低保真等级和质量排序。真实提交要求只保留一个文件，并再次确认文件及完整保真配置；不自动更改路线或降级。当前 Native 初始化会如实产生失败的真实任务记录，显示原生会话/引擎尚未接入；不生成演示完成、转换文件或实测保真报告。

独立组件预览没有 EntryAbility 注入的上下文时，文件入口不可用，显示预览提示，完整目录与演示仍可用。该降级逻辑已进行宿主测试；本轮未实际点击 Previewer。

## 实际模块与约束

| 模块 | 职责 |
| --- | --- |
| SessionModels | 三类输入 DTO 及可注入的平台契约 |
| FormatDetector | 遍历完整注册目录，扩展名优先、MIME 回退，未识别返回空字符串 |
| HarmonyFilePlatform | CoreFileKit Picker、URI 描述符、分块文件读写、statfs 与 SHA-256 |
| FileAuthorizationManager / Service | 授权快照、目录所有权、预算、串行复制、移除及幂等清理 |
| AuthorizedInputTask | 真实输入校验、现有 Native 会话/工作区 API、原请求协议和 prepare |
| ConverterPage / TaskStore / EntryAbility | 新入口、真实失败记录、所有权转交及 Ability 清理 |

检测覆盖原目录：PDF、DOCX、PPTX、XLSX、TXT、MD、JPEG（含 JPG）、PNG、WEBP、HEIF、MP3、WAV、FLAC、AAC、M4A、OGG、OPUS、WMA。没有新增 DOC、EPUB 或视频格式。扩展名/MIME 只是推断，不代表已解码或确认无保护。平台 Picker 只返回 URI，适配器从描述符读取大小，用对应注册 MIME 作提示；其他适配器提供不一致的 MIME 时记录警告。真正的内容、保护和发布能力仍受原 Native 门禁约束。

使用 Picker 临时只读授权，不新增 FILE_ACCESS_MANAGER 或网络权限。依据见 [OpenHarmony 用户文件选择说明](https://github.com/openharmony/docs/blob/master/en/application-dev/file-management/select-user-file.md)及本机 API 26 声明。原 URI 不进入 Native 请求或任务日志。

副本位置为 `cacheDir/workspace/<随机会话 ID>/inputs/<随机文件 ID>`，不把原文件名拼成目录。初始 stat、实际拷贝字节和目标 stat 共同检查大小；单文件上限 100 MiB，会话总量 300 MiB，复制前检查空间并保留 1 MiB 余量。单次缓冲 256 KiB，处理部分读取/写入，不把整个文件读入内存。摘要从实际副本计算，返回小写 SHA-256；校验完成后才发布 AuthorizedFile。失败回滚部分副本，两个描述符均尝试关闭。

## Native 接入与生命周期

本地 SessionContext.sessionId 是输入所有权标识，workspaceRef 是本地目录，不能冒充 Native 授权句柄。提交先调用原 `initializeSession(SessionInit)`，再 `registerWorkspace(WorkspaceGrant)` 获得 Native session/workspace，构造 PreparedInput 和原 ConvertRequest。初始化链路五秒超时，迟到回调不能入队；迟到注册尝试 releaseTask。

NativeBridge、NativeProtocol、NativeTaskRunner 和 C++ 完全保留。真实队列继续使用原能力/发布证据、输入探测、保护、保真和结果校验。当前会话/工作区 API 拒绝 `UNSUPPORTED_FEATURE:MIGRATED_CONTRACT_NOT_IMPLEMENTED`，并未实现真实引擎端到端转换。

提交前页面离开清理未转交副本，移除最后一个文件销毁会话。提交后页面不能修改已认领输入，任务持有副本；排队取消先释放注册，运行取消等待 Native 调用及释放结束，再清理副本。Ability 退出清理全部受控会话；旧 Ability 迟到清理绑定旧管理器，不能关闭新管理器。并发销毁共享 Promise，失败保留所有权供重试。

清理适用于正常生命周期。系统强制终止未必触发 onDestroy，崩溃恢复扫描尚未实现，不能保证强制终止后零残留。输出工件仍归原 Native 生命周期，结果导出尚未实现。
