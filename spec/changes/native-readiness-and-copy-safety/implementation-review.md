# 原生就绪与副本安全：审核及兼容方案

日期：2026-09-30；基线 e58878fb0d4d19429748b892cfa3716691fa2343。

## 逐项核对

- F-01 属实：BridgeProblem 缺少 what()。当前 Boundary 专门按 reason 捕获，并非已确认丢失所有错误，也未证实该项导致崩溃；补齐诊断接口并测异常消息寿命。
- F-02 属实：五个引擎、initializeSession/registerWorkspace/probeInputs 均占位。仅替换 image 工厂不能完成真实链路。
- F-03 是尚未落实的资源方案，不能认定存在现成全文件读入：PreparedInput 只有相对路径、字节数、摘要，没有 contentRef 或文件字节；TaskContext 明确由实现管理句柄。已有 ArkTS 256KiB 分块复制和 100MiB 单文件上限。本机 SDK 头文件未发现建议中的 napi_fs API；工作线程须用 C++/系统文件 API，不应访问 JS 值。
- H-01/H-02/H-03 属实：JSON 深拷贝、全目录查询后扫描、历史反转副本可做兼容优化。目录当前 18 项；维持防止调用者篡改内部缓存的隔离保证，不改成可变共享引用。
- H-04 的静态入口为上一阶段明确批准的兼容委托。可加 @deprecated/JSDoc 标注、使新生产路径显式注入；不删入口或破坏旧构造函数/预览/测试。
- H-05 属实：增加真实 C++ 主机可执行测试及 CTest，覆盖全部错误码、五类工厂、占位不成功、RAII 和桥接故障边界；主机 mock NAPI 测试不等于鸿蒙运行。
- H-06/H-07 的实现缺口属实，但位置描述需纠正：当前 converter.h 没有 DocumentIR/PageNode/TextRun/StyleRef 完整结构，只有 validationViewRef 等契约。通用保真与 IR 尚未实现；Demo 报告是固定演示规则，并非真实测量，也不是随机保证。现有 Native 门禁不会把占位结果宣称成功。validationProfileId 已在路线配置中存在，无需新增协议字段。
- M-01 由生成器维护：修改生成器和生成结果，保持五工厂、顺序/ID/签名及非法 ID 返回空。
- 附件在 M-02 的问题位置处结束；未收到该项详细要求或独立开发提示词。

## 可直接实施且不改变现有功能

1. F-01 what() 补齐和可执行 C++ 测试。
2. H-01 显式逐字段深拷贝会话、授权文件、结果、请求与目录对象，覆盖既有类型声明的所有字段，保留可选字段和嵌套隔离；以字段覆盖测试防遗漏。
3. H-02 ID/别名/分类索引：新增查询返回隔离对象，保留 listFormats 的完整有序可变副本接口。
4. H-03 反向循环淘汰，维持 100 历史、活动任务保护、结果释放顺序。
5. H-04 兼容入口弃用说明，作用域内显式注入；原接口不移除。
6. H-05 本机 C++/CTest，以及 NDK 双 ABI 与 ArkTS/HAP 回归；测试目标只在明确开启时加入，测试程序不进入应用包。
7. M-01 工厂索引；M-02 仅补目标级警告和检查已有 Debug/Release 优化，暂不猜测缺失的具体要求。

## 需要用户审核的功能调整

真实 JPEG→PDF 将把旧 Native 占位路径变为可执行路径，涉及会话/工作区授权、输入摘要/保护/内容探测、取消/输出所有权、真实验证证据和 IR，而非单个工厂替换。建议沿用 13 API、schemaVersion=1、已有 resourceBudget/validationProfileId，不新增 SetInputStream/streamingHint 破坏契约。流式访问通过新增可选 C++ 适配层实现。

用户已选择“先完成兼容优化与隔离的 JPEG→PDF 原型，真实链路接入另审（推荐）”，并确认 M-02 无后续补充。原型在 prototypes/jpeg-pdf 中独立构建，输入子集、依赖、几何、方向/ICC、错误和预算边界见其 README。原有 18 格式/43 路线、筛选排序、演示及 Native 占位行为保持；主机实验不改变 planned/极致保真或 available 状态。

## 本轮实际进展

F-01、H-01～H-05 和 M-01 的兼容部分已实现。应用/测试包编译及 205 项 ArkTS 宿主检查、13 项 C++/mock NAPI 可执行测试通过。H-04 保留原默认参数和静态委托，首页/任务页改用 ServiceContainer 的实例；不是删除所有兼容静态入口。M-02 已添加目标级警告和默认关闭的主机测试开关，Debug 实际使用 SDK 的 -O0，Release 未构建验收，不擅自覆盖工具链优化。

独立 JPEG→PDF 原型已编译并通过 4 项 C++、15 项独立 PDF 解析/渲染集成检查，含 64 KiB 分块、图片 IR、DCT 原字节嵌入和候选载荷身份校验；这是隔离实验，不是应用转换成功。Native 会话/工作区/探测/执行与完整通用保真仍待另审和实现。M-02 后文由用户确认没有。当前真实可用路线仍为 0。验证详情见 [验证记录](../../../docs/VALIDATION-NATIVE-READINESS.md)。
